# 표창키우기 — 합체 (Shuriken Merge)

2048류 그리드 합성 + 방치형 성장 게임. **의존성 없는 단일 `index.html`** 하나가 게임 전부입니다.

같은 레벨 표창 둘을 합치면 한 단계 위가 되고, 그리드 위 표창들이 시간당 골드를 만들어냅니다.
최고 레벨을 밀어 올리고, 윤회(輪廻)로 환생하고, 초월(超越) 너머의 무한 심층까지 —
도구들은 성장하며 하나씩 열립니다(점진 공개).

## 실행

```bash
# 그냥 브라우저로 열면 됩니다
open index.html            # macOS
start index.html           # Windows

# 또는 로컬 서버
python3 -m http.server 8000
```

빌드 없음, 설치 없음, 외부 요청 없음. 저장은 localStorage.

## 핵심 루프

- **생성은 순수 시간 게이트** — 골드는 강화에 쓰는 부수 자원 (수비형 경제 아님)
- **탭→탭 합성** (드래그도 지원) · 그리드가 가득 차면 합쳐서 공간을 비우는 것이 긴장의 축
- **결정 축들**: 무엇을 제련할까(제련 모드) · 보유 vs 매도(오늘의 시세) · 보유 vs 파견(원정)
  · 悟를 스킬에 쓸까 각인에 쓸까 · 어떤 핸디캡 층에 도전할까(시련의 탑 → 무한 심층)
- **정취**: 진행이 소리가 되는 상태 반응형 생성 음악 (🎵 토글)

## 개발

```bash
npm run check            # JS 파스 검증 + 순수 로직 테스트 (1000+)
npm run scan             # 데드 코드/중복 id 자문 스캔
npm i --no-save playwright-core
npm run verify:browser   # 헤드리스 시스템 Chrome — UI 패널 실클릭 검증
npm run verify:gameplay  # 실플레이 스모크 (합성/세이브 왕복/오프라인/윤회)
```

테스트 하네스는 `index.html`에서 `<script>`를 추출해 브라우저를 스텁으로 대체한 vm에서
순수 로직만 검증합니다 (`tests/harness.js`). 아키텍처·불변식·시스템별 설계 노트는
[CLAUDE.md](CLAUDE.md)에 있습니다 — 특히 **의식-패리티**, **마일스톤 점프 교차**,
**점진 공개 등록 규칙**은 새 코드가 반드시 지켜야 하는 계약입니다.
